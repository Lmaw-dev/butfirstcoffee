# Supabase + Netlify Setup

This project is now wired to Supabase for auth and data.

## Tables

Run this SQL in the Supabase SQL editor:

```sql
create table if not exists public.products (
  id bigint generated by default as identity primary key,
  name text not null,
  category text not null,
  price numeric(10,2) not null,
  image text,
  available boolean not null default true,
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now()
);

create table if not exists public.orders (
  id bigint generated by default as identity primary key,
  items jsonb not null,
  total numeric(10,2) not null,
  paid numeric(10,2) not null,
  change_amount numeric(10,2) not null,
  status text not null default 'pending',
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now()
);

create table if not exists public.staff (
  id bigint generated by default as identity primary key,
  name text not null,
  role text not null,
  username text not null unique,
  active boolean not null default true,
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now()
);

alter table public.products enable row level security;
alter table public.orders enable row level security;
alter table public.staff enable row level security;

drop policy if exists "public can read products" on public.products;
create policy "public can read products"
on public.products for select
to anon, authenticated
using (true);

drop policy if exists "authenticated can manage products" on public.products;
create policy "authenticated can manage products"
on public.products for all
to authenticated
using (true)
with check (true);

drop policy if exists "public can create orders" on public.orders;
create policy "public can create orders"
on public.orders for insert
to anon, authenticated
with check (true);

drop policy if exists "authenticated can manage orders" on public.orders;
create policy "authenticated can manage orders"
on public.orders for select, update, delete
to authenticated
using (true)
with check (true);

drop policy if exists "authenticated can manage staff" on public.staff;
create policy "authenticated can manage staff"
on public.staff for all
to authenticated
using (true)
with check (true);
```

## Admin login

Create a Supabase Auth user and set its user metadata to:

```json
{
  "name": "Admin Name",
  "role": "admin"
}
```

Use that email/password on the `/login` page.

## Netlify environment variables

```env
REACT_APP_SUPABASE_URL=https://YOUR_PROJECT_ID.supabase.co
REACT_APP_SUPABASE_ANON_KEY=YOUR_SUPABASE_ANON_KEY
```

## Netlify settings

- Build command: `npm run build`
- Publish directory: `build`

The included `public/_redirects` file keeps React Router routes working on refresh.
